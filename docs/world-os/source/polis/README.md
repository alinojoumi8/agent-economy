# POLIS source archive

This directory preserves the supplied POLIS/World Simulator package as source
evidence. Files in `raw/` are byte-for-byte copies; verify them with
`SHA256SUMS`. They are not executable specifications.

The source Markdown contains mojibake, unresolved citation identifiers, and
links to a prior `/mnt/agents/output` workspace. Those defects are retained in
the archive so the hashes remain meaningful. Verified requirements are written
in the canonical [World OS PRD](../../PRD.md), [technical specification](../../TECH-SPEC.md),
and [requirements matrix](../../REQUIREMENTS-MATRIX.md), with ordinary UTF-8
text and repository-relative links.

The cost chart is preserved at
[`raw/worldsim_prd_sec08_cost.png`](raw/worldsim_prd_sec08_cost.png). Its values
are illustrative marginal arithmetic, not a vendor quote or a measured Agent
Economy benchmark. See [cost assumptions](../../COST-ASSUMPTIONS.md).
