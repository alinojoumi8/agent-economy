How this world works

This is a laboratory, not a game. ~100 AI agents — teachers, bankers, founders, journalists — live inside a miniature US-style economy. Each one reads news, holds beliefs, earns, spends, borrows and talks. You observe, inject shocks, and interrogate the world while it runs.

⚖️ The one rule: AI agents propose actions; the deterministic engine validates and executes them. Every dollar is double-entry ledger money — conserved to the cent. The books reconcile every night, or the run halts. That's what makes crashes and bank runs real here rather than hallucinated.

Run an experiment in 4 steps

  1. ▶ Run the world for a few weeks to establish a baseline.
  2. ⚡ Inject a shock — e.g. a false rumor about a bank (purely information, no money touched).
  3. Trace the causal chain: conversations → trust beliefs (Banks panel) → deposit moves (events) → reserves.
  4. 🔮 Ask the Oracle for a probability, and let the resolver score it later. 📄 Report wraps the run up.

python run.py --config runs/base.yaml --replay RUNID                # exact re-run, zero API cost
